# Emigisha logo

Concept P, "Full bowl": a gold sun settling into a bowl held out to receive. The name is set in Outfit SemiBold (600) at -0.03em tracking and converted to outlines, so no font is needed to use these files.

## Colours

| Name  | Hex       |
| ----- | --------- |
| Navy  | `#0E2A47` |
| Gold  | `#F2B33D` |
| White | `#FFFFFF` |

## Files

Each mark comes in four colourways:

- `color`: gold sun, navy bowl and name. Use on white or light backgrounds.
- `reverse`: gold sun, white bowl and name. Use on navy or dark backgrounds.
- `navy`: all navy, for single-colour print on light backgrounds.
- `white`: all white, for single-colour use on photos or dark backgrounds.

| File                                                    | Use                                                        |
| ------------------------------------------------------- | ---------------------------------------------------------- |
| `emigisha-logo-*`                                       | Horizontal lockup. The default logo.                       |
| `emigisha-logo-stacked-*`                               | Symbol above the name, for square or narrow spaces.        |
| `emigisha-symbol-*`                                     | Symbol alone, when the name already appears nearby.        |
| `emigisha-wordmark-*`                                   | Name alone.                                                |
| `emigisha-app-icon`                                     | Rounded navy tile, for app stores and launchers.           |
| `emigisha-avatar`                                       | Square navy tile, for social profiles (platforms crop it). |
| `emigisha-favicon.svg`, `favicon.ico`, `favicon-32.png` | Browser tab.                                               |
| `apple-touch-icon.png`                                  | iOS home screen, 180px.                                    |
| `emigisha-social`                                       | 1200×630 link preview image.                               |

SVGs are cropped tight to the artwork. PNGs have transparent backgrounds, except the tiles and the social image.

## Rules

- Keep clear space around the logo equal to the height of the sun.
- Do not use the horizontal logo narrower than 96px, or the symbol smaller than 16px.
- Do not recolour, stretch, rotate, or add effects.
